中華飯店R イベント設定ツール

期間限定ボスの設定をここで作り、events.json を書き出します。ゲームのURL（index.html）は変わらず、設定した期間だけ自動でボスの見た目が切り替わります。

イベント一覧

日時は日本時間（JST）です。開催中のイベントが複数あるときは、開始が新しいものが優先されます。

書き出し（events.json）

  1. 上の events.json をダウンロード
  2. GitHub の chuka-hanten-r 直下（index.html と同じ場所）の events.json を上書きアップロード
  3. 数分で反映（GitHub Pages のキャッシュ待ち）。ゲーム側は開催期間に合わせて自動で切り替わります

このページに保存機能はありません。書き出した events.json をアップロードして初めて反映されます。
